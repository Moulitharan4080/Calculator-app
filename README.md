Simple Python Calculator

A lightweight and beginner-friendly Python Calculator App that performs basic arithmetic operations: Addition, Subtraction, Multiplication, and Division.
Ideal for learning core Python concepts like user input, functions, and conditional statements.

Features

Add, Subtract, Multiply, Divide, modulus and power

Clean and readable Python code

Works on any system with Python installed

Setup Instructions
1. Install Python

Download and install Python from:
https://www.python.org/downloads/

Make sure Python is added to your PATH.

2. Download the Project

Create a file named calculator.py and paste your calculator code into it.

3. Run the App

Open your terminal or command prompt and execute:

python calculator.py

4. Use the Calculator

You will be prompted to:

Enter two numbers

Choose an operation
